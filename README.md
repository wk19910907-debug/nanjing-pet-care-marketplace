# 南京安心宠

面向南京本地的“上门喂猫 + 遛狗”平台体验版。宠主只提交订单，由平台匹配已认证服务人员，并跟踪上门履约与宠主确认。

## 在线体验

无需安装，直接打开：

<https://wk19910907-debug.github.io/nanjing-pet-care-marketplace/>

在线页面是安全体验版：订单数据只保存在当前浏览器，不会提交到服务器。请勿填写真实手机号、精确住址、门锁密码、支付信息或其他敏感信息。

公开页同时展示两项服务的体验参考价、南京体验区域、平台匹配与履约保障说明、常见问题，以及进入宠主下单体验的快捷入口。页面不提供联系方式，也不承接真实订单。

- 访客可选择服务和体验区域，查看不具约束力的体验参考价，并将这两项选择带入浏览器本地保存的体验下单表单。
- 服务人员可提交仅含体验昵称、服务区域、服务项目和经验说明的申请；平台审核通过后，才会进入符合区域与服务类型的订单匹配池。该流程完全保存在当前浏览器，且不接受真实联系方式、身份证明或其他身份文件。

## 立即使用网页端

Windows 用户直接双击根目录的 `start-local.cmd`，等待终端显示启动成功，然后在 Chrome 打开：

<http://127.0.0.1:43123>

也可以在 Node.js 22 和 pnpm 10 环境中执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

页面中的完整操作顺序：

1. 在公开页选择服务和体验区域后，可点击“按此方案体验下单”带入表单；也可直接选择“宠主”，填写宠物、区域、地址和时间，点击“提交订单”。
2. 选择“平台运营”，为订单选择已认证人员，点击“确认匹配”。
3. 选择“服务人员”，点击“开始服务”。
4. 完成两项履约清单、填写服务记录，点击“提交服务报告”。
5. 回到“宠主”，查看报告并点击“确认完成”。

刷新页面不会丢失订单。需要重新演示时点击“恢复体验数据”。

## 使用微信小程序端

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库的 `apps/miniprogram`。
4. 使用配置中的游客 AppID 打开；如开发者工具要求，可选择测试号。
5. 在首页依次切换“宠主 → 平台运营 → 服务人员 → 宠主”完成同一闭环。

小程序体验数据保存在微信开发者工具本地。原有正式 API 页面仍保留，后续配置真实 AppID、合法域名和生产 API 后可继续接入。

## 当前交付边界

这是可操作的本地体验产品，不依赖 Docker、短信、微信支付、对象存储或公网服务器。为了安全，请勿输入真实门锁密码、手机号、支付信息或精确住址。

正式对外运营前仍需完成：手机号验证、微信支付商户接入、文件存储、地图定位、生产数据库、域名与备案、微信小程序审核、隐私政策和服务人员真实审核流程。
