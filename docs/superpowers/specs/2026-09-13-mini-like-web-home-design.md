# 小程序式网页首页设计

目标：让网页版（公开演示与真实试运营入口共用的 `PublicLanding`）在手机宽度下拥有小程序的内容层级和操作节奏，同时保持白色、整洁的商城感。参考用户提供的猫巷小程序截图和猫巷公开服务页面；只借鉴信息架构，不复制品牌、图片或虚构数据。

用户已经确定的业务模式不变：宠主选择上门喂猫或遛狗、提交时间与必要信息，平台匹配服务人员。网页不展示“自选宠托师”、虚构评分/销量、未实现的商城与消息模块。

## 页面结构

顶部为“安心宠”品牌和一个真正通向预约流程的胶囊按钮“上门服务 · 选择时间”。其下是 4 个快捷入口：当前后台启用的喂猫与遛狗、我的订单、安心保障。再下是紧凑横幅，保留现有自有素材与预约主按钮；两个服务卡片展示后台起步价，并直接带入对应预约。页面下方保留真实流程说明、保障、FAQ。手机固定底栏为“首页、服务、预约、订单”，每项都能触达对应内容或功能；无空壳 tab。

公开 GitHub Pages 仍需清晰标为仅浏览器演示；真实试运营入口保留现有后端路径与未登录/恢复订单流程。后台禁用的服务不得出现在快捷入口与服务卡片中。手机优先让顶部、快捷入口、横幅和首个服务卡片在较短滚动中出现，桌面则保持一致的白色设计系统。

验收：组件测试验证导航、快捷入口、禁用服务、价格来源和不虚构人员信息；响应式样式检查；完整前端测试、类型检查和构建通过。正式运营闭环不在此次纯网页排版改动中宣称完成。
