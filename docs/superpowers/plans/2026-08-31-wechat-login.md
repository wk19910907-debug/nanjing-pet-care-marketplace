# 微信登录实现计划

> 执行方式：复用现有隔离 worktree，按测试驱动实施；用户已要求自主完成，不重复要求选择方案。

1. 红灯：为配置、微信网关、生产登录路由与现有会话服务新增测试，运行并确认预期缺失失败。
2. 绿灯：实现有界微信交换网关、可选配置、限流路由、AppID 隔离的身份与现有会话集成；仅放行必要的无 Cookie 原生登录请求。
3. 回归：运行 API 定向测试、全仓 check、原生/网站构建。按代码复核技能请求独立安全复核并处理问题。
4. 交付：更新运维文档与 Vault 项目总结，记录真实微信和公网服务尚未验收的边界；同步已验证代码，确认本地禁用态不会伪造成功。

不得把 AppSecret、认证密钥、临时 code 或令牌写入仓库/Vault。测试使用专用临时数据库，不修改已有业务数据。
