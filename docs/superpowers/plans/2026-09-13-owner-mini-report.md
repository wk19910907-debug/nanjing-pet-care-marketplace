# 宠主小程序真实服务报告

目标：让宠主在小程序内查看服务人员提交的喂猫/遛狗清单和履约照片，并能在异常时向平台提交售后。维持平台派单，不复制猫巷品牌或无关模块。

1. 为小程序增加报告响应校验和证据临时链接请求；只接受当前订单的报告、允许的清单字段及安全的链接格式。
2. 先写失败测试，覆盖有/无报告、非法响应、带鉴权的临时链接请求、重复点击与页面卸载。
3. 把宠主报告页从占位文案改为真实报告、照片按需加载、重试、投诉表单和清晰状态。
4. 调整订单详情入口文案；运行小程序测试、类型检查、lint 和构建。不能把本地小程序构建等同于微信正式发布。

验收边界：此步骤解决小程序的服务报告缺口，不代表已达到猫巷整体 90% 功能一致；商城、社区、认证、公开 API 和微信支付仍需分别验收。
